Privacy Policy

Last updated: August 30, 2026

Core summary: DBV PDF2Deck is built on strict privacy-by-design principles (Zero-Cloud Privacy). It does not collect, transmit, or store on any external servers any personal information, PDF documents, images, or exported presentations. There are no user accounts, no advertisements, no third-party analytics, and zero telemetry. All optical character recognition (OCR), canvas editing, and PowerPoint export operations are performed 100% locally on your own computer.

1. Local Processing of PDFs, Images, and Presentations

All PDF files and images (PNG, JPG, WEBP) that you open, process, or edit in DBV PDF2Deck are analyzed exclusively in your computer's local memory and processor/GPU using open-source local engines (EasyOCR, OpenCV, and PyMuPDF).

The application maintains no remote telemetry servers or cloud databases. Your documents, reports, slides, and infographics never leave your machine and are never transmitted over the internet.

2. Data Stored on Your Device

To provide a smooth and comfortable user experience, DBV PDF2Deck saves the following preferences strictly on your local device storage (localStorage):

  • Interface settings: Selected language preference (Spanish or English).
  • Export preferences: Default slide rendering resolution for PowerPoint backgrounds (150, 300, or 600 DPI) and enabled export formats (.pptx, .pdf, .md).

This configuration data stays exclusively on your machine and can be cleared at any time by resetting your application settings or uninstalling the desktop application.

3. Network Connections & Offline-First Operation

DBV PDF2Deck is engineered with a strict 100% offline-first architecture:

  • Zero external CDN dependencies: All typography, icons, styles, and interface assets are self-hosted and packaged within the application bundle.
  • Zero telemetry or tracking: The application does not send analytics, telemetry, diagnostics, or tracking pings to any remote server.
  • Full offline capability: All features — including OCR recognition, block editing, Magic Eraser inpainting, and PowerPoint generation — operate without requiring an active internet connection.

4. Microsoft Store and App Store Distribution

If you install DBV PDF2Deck through the Microsoft Store or another application marketplace, the platform operator may collect aggregate anonymous telemetry, download stats, and OS crash reports under its own terms of service. For further information on how Microsoft handles this data, please refer to the Microsoft Privacy Statement.

5. Open Source & Transparency

DBV PDF2Deck is free and open-source software licensed under the MIT License. The complete source code is publicly available for inspection, audit, and community contribution at github.com/davidbuenov/dbv-pdf2deck.

6. Contact

If you have any questions or feedback regarding this privacy policy, you can contact the author by opening an issue on GitHub Issues or via the official website davidbuenov.com.
